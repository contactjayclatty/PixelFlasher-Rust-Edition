Install

Windows x64. Check the ZIP first.

Published builds are Windows only. macOS and Linux are not packaged. Platform-tools, scrcpy, and the Python app are not inside the ZIP.

Get the latest ZIP Get platform-tools
  1. 01

    Download

    From Releases, take the latest Windows ZIP and checksums.sha256.

  2. 02

    Verify

    Check the ZIP's SHA-256 against the matching line. Do not skip this.

  3. 03

    Launch

    Extract the archive and start PixelFlasher.exe. It will not look for a phone by itself.

  4. 04

    Point at platform-tools

    In Settings, select the folder that contains both adb.exe and fastboot.exe. The app checks for both.

Where your library lives

Default data directory%LOCALAPPDATA%\PixelFlasherRust

Set PIXELFLASHER_DATA_DIR before launch to use another folder. That is a different workspace, not a copy of the old one.

First session

Select the device before you prepare anything.

  1. 01

    Open Settings

    Confirm the platform-tools folder. If Scan finds nothing later, this is the first place to look.

  2. 02

    Connect, then Scan

    Put the phone in the mode the task needs. Press Scan. Select that device before you inspect or prepare an operation.

  3. 03

    Add firmware

    In Firmware & Images, add a supported file or open a Factory or Full OTA catalog. Catalog access requires you to acknowledge Google's terms. Beta, canary, and watch catalogs are not in 0.3.4.

  4. 04

    Read the plan

    Check the device, files, commands, wipe, and slot. Destructive work asks for a typed confirmation for that device. Stop if you do not have a way to recover the phone.
