Coverage · 0.3.4

In the app is not proven on a phone.

Every device-mutation path below is hardware-unverified. Tests cover parsers, planners, and selected workflows.

In the app Partial Planned or manual Not in this release
Device discovery, labels, properties, slotsIn the app

Development did not include a live-device scan.

Platform-tools checkIn the app

Still warns on platform-tools 34.0.0 through 34.0.4.

Boot-image library and checksumsIn the app

Legacy database import is read-only, and only when the recorded SHA-1 still matches the file.

Factory ZIP and Full OTA payloadIn the app

Incremental OTAs are rejected. Samsung Odin/AP handling is not equivalent to upstream.

Factory flash, image flash, OTA sideload, live bootPlanned in the app

Live boot accepts boot images only. Nothing here has been flashed on hardware.

Root providers and modulesPartial

Six adapters check APK identity and version. Scripts are unverified. Unpinned or canary builds are rejected.

GKI kernel replacementManual plan only

You pick the kernel. There is no automatic KMI-compatible download.

Packages, logcat, scrcpy, ShizukuIn the app

Command plans only. They were not run against a phone.

Partition backup and restore planningIn the app

A match checks device, build, slot, and content. That does not prove the restore will boot.

Google Factory and Full OTA catalogsStable only

Requires an explicit acknowledgement of Google's terms. Beta, canary, and watch are absent.

Local MCPOff by default

Reads saved metadata and can queue a desktop review. It cannot run a device operation, a shell, or read secrets.

Not in this release

Other desktops

No macOS or Linux packages. The UI is English only. Upstream ships 23 translation catalogs.

Downgrade and AVB

No AVB downgrade preparation and no no-wipe downgrade workflow.

Root edges

No automated integrity checker, no APatch alternate patch path, and no legacy special Magisk recovery builds.

Line-by-line matrix: docs/PARITY.md. Roadmap: docs/IMPLEMENTATION.md. This is not 1.0.
