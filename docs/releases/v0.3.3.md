# PixelFlasher Rust Edition v0.3.3

A native Rust/egui development preview of PixelFlasher for Windows x64.

This update keeps the nine PixelFlasher destinations and makes the window easier
to scan. The device, Scan, and Inspect stay in one bar. Overview is a status page.
Google factory and full OTA builds are chosen by model, then one table row, then
Download. Boot images, applications, modules, partitions, and backup sets use
column lists. Applications and backup sets can still include more than one row.

## Downloads

- Windows portable ZIP: extract and run `PixelFlasher.exe`.
- Complete source ZIP: Rust workspace, tests, documentation and build/packaging tools.
- `checksums.sha256`: archive and executable SHA-256 values.

The executable name and existing user-data directory are preserved. Android
platform-tools, drivers and scrcpy are not bundled. MCP starts disabled and cannot
approve or execute device changes. No Python runtime is needed by the application.

## Validation and limits

77 tests, formatting, strict Clippy, the Windows release build, and CLI/MCP smoke
checks pass locally. Dependency license notices, upstream attribution, the parity
matrix and validation reports are included in the packages.

**Development prerelease: full upstream parity is incomplete and physical-device
flashing, root, and restore workflows remain hardware-unverified.** Review PARITY.md
and IMPLEMENTATION.md before using device operations. This is an independent port,
not an upstream-maintainer or Google-endorsed release.
