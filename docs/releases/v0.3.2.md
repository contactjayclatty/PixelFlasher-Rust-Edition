# PixelFlasher Rust Edition v0.3.2

A native Rust/egui development preview of PixelFlasher for Windows x64.

This release uses the **PixelFlasher Rust Edition** name and organizes the shared
backend into its own Cargo crate. It includes Studio navigation, six root-provider
adapters, reviewed operations, durable journals, backup manifests, patch lineage
and optional local MCP inspection/planning. Google factory/OTA catalogs load after
explicit terms acknowledgement.

## Downloads

- Windows portable ZIP: extract and run `PixelFlasher.exe`.
- Complete source ZIP: Rust workspace, tests, documentation and build/packaging tools.
- `checksums.sha256`: archive and executable SHA-256 values.

The executable name and existing user-data directory are preserved. Android
platform-tools, drivers and scrcpy are not bundled. MCP starts disabled and cannot
approve or execute device changes. No Python runtime is needed by the application.

## Validation and limits

75 tests, formatting, strict Clippy, Windows release builds and CLI/MCP smoke checks
pass locally. Factory and OTA metadata retrieval was verified live. Dependency
license notices, upstream attribution, parity matrix and validation reports are
included in the packages.

**Development prerelease: full upstream parity is incomplete and physical-device
flashing/root/restore workflows remain hardware-unverified.** Review PARITY.md and
IMPLEMENTATION.md before using device operations. This is an independent port,
not an upstream-maintainer or Google-endorsed release.
