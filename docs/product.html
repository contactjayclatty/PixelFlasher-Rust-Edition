Product

Nine workspaces. One device bar.

Scan and Inspect stay at the top. The rest of the app is where you prepare work. None of these screens talk to a phone until you ask.

HOME

Overview

Readiness, plus status for the device, the image library, and platform-tools. Recent operations show up here. Interrupted ones are not replayed.

FIRMWARE

Firmware & Images

Local files, the boot-image library, and the Google Factory and Full OTA catalogs.

UPDATE

Update Studio

Factory, Full OTA, standalone-image, and live-boot plans. Live boot is boot images only.

ROOT

Root Studio

Magisk, KernelSU, KernelSU-Next, SukiSU, Wild_KSU, and APatch. Partial. Unpinned builds are rejected.

APPS

Applications

Package lists and supported package actions. Plans only. Not run against a phone in development.

RECOVERY

Backups & Recovery

Partition backups and checksum-bound restore plans. A match is not proof the phone will boot.

DIAGNOSTICS

Diagnostics

Properties, slots, log snapshots, and a subset of integrity checks.

WIRELESS

Wireless

Pair, connect, and disconnect wireless debugging.

SETTINGS

Settings

Platform-tools folder, data location, and optional local MCP. MCP is off unless you turn it on.

Order of operations

The path every device write takes.

01Scan
02Select the device
03Prepare a frozen plan
04Review target, files, and commands
05Type the device confirmation
06Run

A command that returned is not proof the phone will boot. Read the limits.
